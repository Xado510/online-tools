四、完整配置教程

4.1 首次配置流程

1. 启动服务确认桥接服务已运行
2. 打开系统访问线上页面或本地页面
3. 打开设置点击右上角星匣机器人
4. 确认服务连接无需填写服务地址，系统自动连接主电脑桥接服务
5. 配置京东 Cookie执行“宝藏自动获取”
6. 配置展翅 Cookie执行“展翅自动获取”
7. 保存并测试输入快递单号或履约单号查询

4.2 启动桥接服务

  1. 打开命令提示符或 PowerShell。
  2. 进入系统目录：C:\Users\zx173\Documents\New project\outputs\jd-unpack-system
  3. 执行：python jd_repair_bridge.py
  4. 看到 JD repair bridge ready at http://127.0.0.1:9090 表示启动成功。
  5. 已验证的地址：http://127.0.0.1:9090。

本机已配置开机自启动，正常情况下不需要每次手动启动。若服务未运行，其他电脑查询会失败。

4.3 服务地址自动配置

  1. 服务地址已内置在线上页面中，无需手动填写。
  2. 其他电脑打开线上网址后，会自动连接主电脑桥接服务。
  3. 只有主电脑桥接服务未启动时，才需要检查主电脑是否开机、是否联网。

4.4 配置京东维修 Cookie

推荐方式：宝藏自动获取

  1. 在电脑浏览器登录：https://digital-ins.jd.com/repair
  2. 打开拆包系统“设置”。
  3. 点击“宝藏自动获取”复制命令。
  4. 回到京东维修页面，按 F12 打开控制台。
  5. 如果提示 allow pasting，先输入 allow pasting 再回车。
  6. 粘贴命令并回车，等待提示“已发送到拆包系统”。

手动方式：复制 Cookie

  1. 登录京东维修页面，按 F12 打开 Network。
  2. 在页面执行一次查询。
  3. 找到 queryFacilitatorOrderByStateAndCode 请求。
  4. 复制 Request Headers 中 Cookie: 后的完整内容。
  5. 粘贴到拆包系统“设置”的“Cookie”输入框，点击保存。

4.5 配置展翅备件条码

推荐方式：展翅自动获取

  1. 在电脑浏览器登录：https://jdservice.jdl.com/spc/repair/servicebilllist
  2. 打开拆包系统“设置”。
  3. 点击“展翅自动获取”复制命令。
  4. 回到展翅页面，按 F12 打开控制台。
  5. 粘贴命令并回车，等待提示“已自动配置京东物流 Token”。

手动方式：配置京东物流 Cookie

  1. 登录展翅页面，按 F12 打开 Network。
  2. 点击一次“查询”，找到 spcapi/mcsServiceBill/page 请求。
  3. 复制 Request Headers 中 Cookie: 后的完整内容。
  4. 粘贴到拆包系统“设置”的“京东物流 Cookie（可选）”。
  5. 点击保存。

4.6 配置条码打印

  1. 在“设置”中找到“条码打印软件路径（可选）”。
  2. 默认路径为：D:\we\data\xwechat_files\wxid_4m1kqcgnvn2v22_d9be\msg\file\2026-07\条码打印软件\条码打印软件\BarPrinter.exe
  3. 如果软件安装在其他位置，填写实际完整路径。

4.7 保存并验证配置

  1. 点击“保存”。
  2. 进入“扫码拆包”。
  3. 输入快递单号或履约单号，例如 JDX057168922378。
  4. 点击“查询”。
  5. 确认页面显示履约单号、履约模式、备件条码。
  6. 切到“历史记录”确认包裹已同步。

五、扫码拆包

4.1 查询快递单/履约单

  1. 进入“扫码拆包”。
  2. 支持输入快递单号或履约单号，例如 JDX057168922378 或履约单号。
  3. 支持扫描全码，例如 JDX056229338452-1-1-，系统会自动识别为 JDX056229338452。
  4. 点击“查询”。
  5. 系统会自动连接京东维修后台，查询维修信息并自动确认接机。
扫码拆包
查询批量分配
包裹信息运单号、履约单号、主商品三级类目、门店名称、履约模式、备件条码
商品核对显示主商品名称、SKU、数量

4.2 自动接机逻辑

  • 如果订单尚未接机，后端会自动调用确认接机接口。
  • 如果订单已经接机，系统会跳过接机，开始循环查询备件条码。
  • 接机后每 3 秒查询一次展翅备件条码，最多循环 5 次，共约 15 秒。
  • 查到备件条码后自动同步；15 秒内未查到会自动挂入异常处理。

4.3 批量分配

点击“批量分配”会复制历史记录中所有符合以下条件的备件条码：

  • 履约方式不是“维修”。
  • 已经同步到展翅备件条码。

复制结果每行一个条码，可直接粘贴到展翅系统。

六、历史记录

  • 查询成功后，包裹信息会自动写入历史记录。
  • 历史记录按时间倒序显示。
  • 支持按运单号或履约单号搜索。
  • 支持按状态筛选、按日期筛选。
  • “批量分派”复制非维修备件条码。
  • “清空历史”会清空全部历史记录，请谨慎操作。

七、异常处理

以下情况会自动挂入异常处理：

  • 无法接机
  • 无法生成备件条码
  • 非此业务快递

异常列表第一列显示“履约单号”，没有履约单号时显示 --。

点击“处理”后，该异常会自动清空。

“清空异常”只能清空已处理记录，未处理记录不会被清除。

九、条码打印

  1. 确认条码打印软件路径已配置。
  2. 查询包裹并确认已有履约单号和备件条码。
  3. 点击“确认拆包”后，系统会自动触发打印。
  4. 打印内容：履约单号前面带两个空格，备件条码放在下一行。

十、多电脑与公网访问

线上地址：https://xado510.github.io/online-tools/jd-unpack-system/

网页本身可在不同电脑、手机、不同网络打开。

京东查询、自动接机、备件条码同步依赖主电脑上的桥接服务；主电脑关机或断网时，其他设备无法查询。

条码打印依赖安装打印软件和打印机的电脑，云服务器无法直接打印。

十一、常见问题

问题处理方式
查询提示无法连接服务确认主电脑已开机、联网且桥接服务已启动
查询提示 NotLogin / 未登录重新登录京东维修页面，并执行“宝藏自动获取”
备件条码不出来确认已执行“展翅自动获取”；系统每 3 秒查询一次，15 秒未生成会自动挂入异常处理
打印失败确认打印软件路径、履约单号、备件条码、本地打印机
历史记录没有同步重新查询一次，系统查询成功后会写入历史记录
自动接机失败查看页面提示，必要时检查京东维修后台订单状态
